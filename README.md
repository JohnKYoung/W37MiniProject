Product List management system
The program requests entry of:
Product category
Product name
Price

Level 1
Store products in a list
Add products dynamically
Present all added products

Level 2
Use 2 classes: Product and ProductManager
Sort products from lowest to highest price
Display output price at the bottom of the output table
Use explicit methods for:
- AddProduct()
- ShowProducts()
- CalculateTotal()

Level 3
Add proper error handling for invalid inputs 
Prevent entry of invalid prices
Allow users to continue adding products after showing the list
Use LINQ
